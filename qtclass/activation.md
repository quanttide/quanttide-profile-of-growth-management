# 激活（Activation）

**激活定义：完成第一个课堂任务（不是报名、不是进群）。**

## 现状

- 申请走 hr 邮箱 → 审核响应（现场示范：确认基础 → 肯定经验 → 发任务书）
- 任务完成发代金券（100 券/个）已是制度
- 学习中心已披露参与方式与价格（v0.1.2-beta.6）

## 该做的事

1. **首任务闭环**：任务 → 发券 → 学员看到券能换一对一咨询——激活闭环闭合的关键是"券的购买力可见"（prices 已披露，闭环只差完成后的引导）
2. **任务门槛设计**：开源协作入门类任务（已在计划）——低门槛、有真实产出、熟悉协作流程
3. **激活度量**：申请 → 首任务完成率；首任务完成 → 第二次参与的转化
