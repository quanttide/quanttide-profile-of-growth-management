# 量潮课堂增长档案

qtclass 的 AARRR 增长模型——内部经营视角。业务本质：信任生意，学员毕业即 qtdata/qtcrowd 的人才池。

三形态分层：**校企合作买信用**（战略投入）、**定制课现金流**（面向企业/团体）、**标准课走量**（获取器，可低价/免费）——三形态是同一内核不同服务深度。

## 当前重点：激活

券发行侧已跑通（四渠道发券：实训任务/众包/代表履职/初审奖励），但核销侧为零：学员拿了券没有消费场景或没意识到消费场景。

**当前全部增长重点在 Activation**——把"发出去的券"变成"被用掉的券"，激活闭环才算闭合。**核销率（发券 → 核销）是当前最重要的单一指标**。

## 运营下放：练习兼考核

把可标准化的运营工作**下放给学员作为练习兼考核**（完成任务挣券 → 运营同步完成），管理层把精力**上移**到方向、定价、体系设计：

| 下放的运营工作 | 双重收益 |
|---|---|
| 支持案例蒸馏（journal → profile 条目） | 学员读懂业务（练习）+ 解决方案库增厚（运营） |
| 学习中心/官网内容维护 | 站点持续更新 + 产品方向学员的实战练习 |
| 案例内容化（学员成果 → 展示素材） | 推荐素材生产 + 写作训练 |

下放设计原则：**每项下放工作本身就是一个标准任务**（有任务书、有验收准则、有代金券）——运营完成度与学员考核共用同一套体系，"考核体系同时就是教育体系"在增长域的落地。

管理层上移的方向：激活闭环的设计与迭代（本档案）、定价体系设计、关键学员的一对一。
