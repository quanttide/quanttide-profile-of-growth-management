# 推荐（Referral）

## 现状

- 历史自然推荐案例：一位同学参与半年后成长显著，"他周围的同学看他这么强纷纷来，他紧跟着一个人就带了十几二十人来我们团队"
- 组队激励已制度化：合作项目大幅提高两人录取率——"更倾向于直接录取已经磨合好的团队"

## 该做的事

1. **学员成果可展示**：作品集页面（真实课题产出：需求澄清智能体、共识链实验等）——成果是学员社交货币，展示即推荐
2. **推荐双方得券**：把自然推荐变成双向激励，券进 qtclass 消费场景
3. **成长故事脱敏沉淀**：qtclass/index.md 历史版的三条成长链路叙事 + 真实成长故事，是对外推荐的素材库
4. **推荐度量**：老学员带来新学员数
