# 量潮课堂增长模型

> 2026-09-02 定稿的两个关键判断：代金券 = 激活与留存工具（非收入）；当前状态券已发未被用——增长重点在激活环节。

## 两个核心判断

**1. 代金券是激活与留存的工具，不是收入。**

- 代金券的作用是让学员**跨过第一次真实参与**（激活），以及**持续参与**（留存）——它是参与循环的燃料，不是钱。
- **现金收入才进入 Revenue 环节**：一对一咨询（真实价格，按职级档位）、定制课程、校企合作——只有外部现金流入才配叫收入。代金券从收入叙事中移除。

**2. 当前状态：券已发、未被用——先做激活。**

发行侧已跑通（四渠道发券：实训任务/众包/代表履职/初审奖励），但核销侧为零：学员拿了券没有消费场景或没意识到消费场景。**当前全部增长重点在 Activation**——把"发出去的券"变成"被用掉的券"，激活闭环才算闭合。**核销率（发券 → 核销）是当前最重要的单一指标**。

## AARRR 修正后的重点分布

| 环节 | 定位 | 当前动作 |
|---|---|---|
| 获取 | 标准课程是唯一可规模化的获取器 | 零门槛落地页；免费课 = 入口 |
| **激活** | **当前最高优先级** | 首任务 → 发券 → **引导核销**：完成页面引导至咨询预约，让券的购买力可见。核销率从 0 起步 |
| 留存 | 券的第二个作用 | 持续参与的任务流 + 代金券持续挣取——券同时在留存环节起作用 |
| 收入 | 只算现金 | 一对一咨询（五档职级价）、定制课、校企合作；代金券不计入 |
| 推荐 | 组队与成果展示 | 组队提高录取率已制度化；学员作品集展示 |

## 运营下放：练习兼考核

把可标准化的运营工作**下放给学员作为练习兼考核**（完成任务挣券 → 运营同步完成），管理层把精力**上移**到方向、定价、体系设计：

| 下放的运营工作 | 双重收益 |
|---|---|
| 支持案例蒸馏（journal → profile 条目） | 学员读懂业务（练习）+ 解决方案库增厚（运营） |
| 学习中心/官网内容维护 | 站点持续更新 + 产品方向学员的实战练习 |
| 案例内容化（学员成果 → 展示素材） | 推荐素材生产 + 写作训练 |

下放设计原则：**每项下放工作本身就是一个标准任务**（有任务书、有验收准则、有代金券）——运营完成度与学员考核共用同一套体系，"考核体系同时就是教育体系"在增长域的落地。

管理层上移的方向：激活闭环的设计与迭代（本模型）、定价体系设计、关键学员的一对一。

## 度量

- **核销率**（当前北极星）：累计发券 → 累计核销
- 激活漏斗：申请 → 首任务完成率 → 首任务后第二次参与率
- 留存：周活跃参与率、任务连续完成率
- 收入（现金）：咨询预约量与核销额、定制课签约数
