# qtcloud 独立业务化预案

> qtcloud 从"寄生模式"（三业务底座，刻意不获客不收费）转为独立业务后的 AARRR 修改方案。**当前不生效**——触发条件见文末前置检查。独立化时按此重写五阶段文档。

## 核心翻转：三个"刻意不做"全部失效

| 环节 | 寄生模式 | 自营模式 | 改动性质 |
|---|---|---|---|
| 获取 | 刻意不获客，账号被 qtdata/qtclass 带入 | **必须独立获客**——开源生态是唯一规模化通道 | 质变 |
| 收入 | 刻意不收费，成本摊薄 | **必须独立收费**——SaaS/开源商业化 | 质变 |
| 激活 | 首次代金券核销（依附 qtclass 场景） | **重新定义**——用户完成第一个自主价值闭环 | 质变 |
| 留存 | 数据沉淀天然锁定 | 逻辑不变，为外部用户设计渐进沉淀路径 | 量变 |
| 推荐 | 自用背书 | 开源社区变增长引擎 | 量变 |

## 修改后的 AARRR

### 获取 Acquisition

- **主通道：开源生态获客**（意图 innovate.md 三步策略：对标开源项目填充矩阵 → 模块替换+生态绑定 → 社区互动转增长驱动）——开源用户即潜在客户，独立后最大的新增变量
- 辅通道：qtdata 客户 / qtclass 学员带入（寄生通道保留，降级为渠道之一）
- 内容获取：第二大脑方法论内容化（"如何消除人机协作摩擦"系列）——方法论即获客素材
- **新增职能**：独立获客预算与渠道运营（寄生模式不存在）

### 激活 Activation

- **重新定义：用户完成第一个自己的"意图→资产"闭环**——写下第一份意图文档、建第一个 profile、跑通第一次写作云 CLI。不是"用代金券消费"（外部用户没有 qtclass 任务/券场景）
- 分云激活路径（每云一个"啊哈时刻"）：资产云 = 建第一个资产契约；写作云 = 完成第一篇结构化稿件；执行云 = 发布第一个标准化任务
- 开源版激活：clone → 按教程建起自己的第二大脑 → 第一次"结构显性化"体验

### 留存 Retention

- 逻辑不变：数据沉淀即锁定成本。新增外部用户设计：
- **渐进沉淀路径**：先轻（笔记/意图）后重（全库结构）——外部用户不会第一天全量迁入，设计"逐步加深依赖"的阶梯
- 社区留存：GitHub Discussions / 社区互动成为留存组件
- 度量切换：journal 提交数（内部代理）→ 外部用户周活跃写入、资产增长数

### 收入 Revenue（改动最大）

分层收费模式：

| 层 | 内容 | 定价逻辑 |
|---|---|---|
| 开源免费层 | CLI / 核心库 | 永远免费——获客与生态绑定 |
| SaaS 托管层 | 代管第二大脑（用户不维护 git/基础设施） | 按席位/存储 |
| 企业层 | Agent Harness 交付约束、数字资产定价 | 高客单，按组织 |

- **数字资产定价从愿景变产品**：帮企业给无法定价的数字资产建立市场与价格（asset.md 金融学愿景）——qtcloud 独有、市场空白的高价值叙事
- **北极星：外部付费账户数**（替代"成本摊薄"）
- 诚实约束：意图"资本家系统先跑通"的前提不变——对外收费前，内部使用必须已验证产品有效性

### 推荐 Referral

- **开源社区即推荐网络**（innovate.md："把开源社区转化为增长驱动力"）
- 新增：用户第二大脑的公开仓 = 用户替你获客——把"公开分享"设计为产品功能
- 学员作品、客户交付物两条寄生通道继续供料

## 结构性新增职能（寄生模式不存在）

1. **产品独立定价权**——现无价格表，独立后需完整定价体系
2. **开源社区运营**——持续经营 contributor/用户社区（新增人力）
3. **竞争叙事**——对标 Notion / Obsidian / git-based 知识库；差异化 = 结构优先 + AI Native + Agent Harness 约束，不是通用笔记
4. **qtdata/qtclass 关系重定义**——从"母体与器官"变成"客户与供应商"：qtcloud 对内也要证明值得被用（内部客户可换外部工具），这是产品健康度最好的压力测试

## 前置条件检查（独立化触发条件）

意图已埋的验证链，逐项达成才启动独立化：

- [ ] 账号系统覆盖三业务
- [ ] 代金券闭环跑通（发券 → 核销 → 对账）
- [ ] 内部日活稳定（journal 提交量代理）
- [ ] 各云 MVP 叙事目标达成（写作云已生产验证 ✓）

**满足之日，即本预案替换五阶段文档之时。**
