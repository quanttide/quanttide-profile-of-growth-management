# 激活（Activation）

**激活定义：用户完成第一个自己的"意图→资产"闭环**——写下第一份意图文档、建第一个 profile、跑通第一次写作云 CLI。不是消费动作（外部用户没有内部任务/代金券场景），是自主价值创造。

## 分云激活路径（每云一个"啊哈时刻"）

| 云 | 激活动作 |
|---|---|
| 资产云 | 建立第一个资产契约，看到资产关系图 |
| 写作云 | 完成第一篇结构化稿件（分层元数据 + 成熟度标注） |
| 执行云 | 发布第一个标准化任务（意图→责任→机制→验收四卡点被流程化） |

## 开源版激活

clone → 按教程建起自己的第二大脑 → 第一次"结构显性化"体验——把脑内的索引方式显性化为仓库结构（白盒化）。

## 理论依据

认知摩擦方法论（qtcloud.md）：从想法到落地之间有摩擦点，各云各回答一个领域内的摩擦。**用户的"啊哈时刻"就是第一次亲身体验到摩擦被消除**——激活设计围绕让用户尽快走到这一刻。

## 度量

- 注册 → 首个闭环完成率
- 各云激活路径的独立转化
