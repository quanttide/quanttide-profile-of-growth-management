# 留存（Retention）

## 现状

- 交付流程已收敛：需求 → 规格 → 处理 → 交付（以项目为容器）
- 数据工程标准 0.1.0 已可发布（规格层 + 实现层分层）
- 老客户维护不足，回购比例下降——留存是当前最大缺口

## 该做的事

1. **交付进度可见性**：客户能看到项目里程碑与成果——项目管理模块（journal 2026-08-08 已提上日程）支撑
2. **标准随交付沉淀**：交付物附带数据工程标准文档——客户用我们的标准，就持续留在我们的体系里（自我淘汰机制的前提）
3. **客户资产入库**：客户档案是留存的地基——商务了解历史、针对性维护、问题回流转产品输入，全依赖完整的客户档案
4. **留存度量**：老客户回购率、客户档案覆盖率
