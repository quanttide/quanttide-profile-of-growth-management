# 获取（Acquisition）

## 现状

- GitHub 开源组织与公众号是主要公开渠道（"能开源的已开源"）
- 专家脑中的案例与经验未公开——商务经验贵的原因之一（公司层面商务专家仅三人）
- 历史客户群庞大但维护不足，回购比例在下降

## 该做的事

1. **专家案例蒸馏成公开内容**：把"在专家脑中"的交付案例整理为案例页/方案页——每个交付项目脱敏后可公开的部分回流为获客素材
2. **老客户转介绍制度化**：意图已定（growth.md）——通过承认错误、感谢帮助、发放优惠券维护老客户，刺激回购与转介绍；触达节奏固化为标准动作
3. **qtcrowd 通用市场导流**：执行方在通用市场按量潮标准交易积累信用，达标者进入 qtdata 认证供应商池（qtcrowd 意图）——供给侧获客通道
